MARKETPLACE APP - START HERE
============================
What you have: ONE website.
  - The MARKETPLACE is the home page (anyone in the world can browse, sell, and chat).
  - Your school features (Quizzes, Labs, Games, Class Record) are inside ONE button: "Learn".

Two folders:
  website/    -> goes to GitHub (this is your site)
  database/   -> you paste these into Supabase (do NOT upload them to GitHub)

IMPORTANT: I (Claude) cannot log in to your GitHub or Supabase. You do these steps yourself.
The steps are short. Menu names in Supabase can look a little different, but the words are close.


=====================================================================
PART 1 - CLEAN YOUR GITHUB (5 minutes)
=====================================================================
1. Open your repository on GitHub (the one that shows your site).
2. DELETE the old files. For each file below: click the file > click the trash icon > "Commit changes".
      market.html
      marketplace-setup.sql
      migration-existing-supabase.sql
      setup.sql
      shared.css
      README.txt
      files.zip
3. Click "Add file" > "Upload files". Drag ALL the files that are INSIDE the "website" folder:
      index.html, config.js, learn.html, quiz.html, labs.html, games.html, records.html
   (Same names will replace the old ones.) Click "Commit changes".
4. Settings > Pages: Branch = main, Folder = / (root). Save.
   Your address looks like:  https://ashbi12-sys.github.io/YOUR-REPO-NAME/
   Open it. It will say "Almost ready: connect the database". That is NORMAL for now.


=====================================================================
PART 2 - THE SUPABASE PROJECT (10 minutes)
=====================================================================
Choose ONE:

  OPTION A (easiest and cleanest - recommended): make a NEW project.
     1. supabase.com > Dashboard > "New project".
     2. Name: marketplace.
     3. Database password: click "Generate a password" and SAVE it in your notes. Never share it.
     4. Region: "Southeast Asia (Singapore)" (good for the Philippines and Asia).
     5. Plan: Free. Click "Create new project" and wait 1-3 minutes.
     -> You can skip file 1-reset-old-marketplace.sql.

  OPTION B: keep using your existing project.
     Your existing project has an OLD marketplace table that does not match this app.
     You MUST run database/1-reset-old-marketplace.sql first (it deletes the old marketplace
     tables and rows; user logins are kept). Supabase may warn about "destructive operations".
     That is expected. Confirm it.


=====================================================================
PART 3 - CREATE THE DATABASE (3 minutes)
=====================================================================
1. In your project, left menu > "SQL Editor" > "New query".
2. (Option B only) Open database/1-reset-old-marketplace.sql, copy ALL, paste, press "Run".
3. Open database/2-setup.sql, copy ALL, paste into a NEW query, press "Run".
   It must say "Success. No rows returned".
   (If you see a red error, copy the message and send it to me. It is safe to run again.)
4. Check: left menu > "Table Editor". You should see: profiles, listings, conversations,
   messages, reports, blocks, marketplace_admins.
5. Check: left menu > "Storage". You should see a bucket named "listing-photos" marked Public.


=====================================================================
PART 4 - LOGIN SETTINGS (3 minutes)
=====================================================================
1. Left menu > "Authentication" > "Sign In / Providers" (or "Providers") > "Email".
   - Make sure Email is ON.
   - "Confirm email": turn it OFF for now, so you can test quickly.
     (Before you launch to the public, turn it ON and set up your own email sender (SMTP),
      so fake emails and bots are blocked. See the checklist at the bottom.)
2. Left menu > "Authentication" > "URL Configuration":
   - Site URL:  https://ashbi12-sys.github.io/YOUR-REPO-NAME/
   - Redirect URLs: add the same address, then Save.
   (This makes password-reset links come back to your site.)


=====================================================================
PART 5 - CONNECT THE WEBSITE TO SUPABASE (3 minutes)
=====================================================================
1. In Supabase: Project Settings (gear icon) > "API Keys".
   Copy TWO things:
     a) Project URL           looks like  https://abcdxyzabcdxyz.supabase.co
        (also shown in Project Settings > "Data API", or the green "Connect" button)
     b) Publishable key       starts with  sb_publishable_
        (If you only see an "anon" key that starts with eyJ, that works too.)
   !! NEVER use the "secret" key or the "service_role" key. NEVER share your database password.
2. In GitHub: open config.js > click the pencil icon > paste between the quotes:
      url: "https://abcdxyzabcdxyz.supabase.co",
      key: "sb_publishable_xxxxxxxxxxxxxxxx",
      contact: "your-email@example.com",
      operator: "Your name or organization"
   Click "Commit changes".
   Tip: the URL and publishable key are safe to share. You can send them to me in chat and I will
   give you a finished config.js to upload.
3. Wait 1-2 minutes, then open your site and refresh (Ctrl+Shift+R). The home page now shows
   the Marketplace.


=====================================================================
PART 6 - TEST IT (5 minutes)
=====================================================================
1. On your site click "+ Sell" > "Create account". Sign up.
2. Post an item with 1-2 photos.
3. Open the site on another phone or browser. Sign up as a different person and tap
   "Message seller". Send a message. Check the first account: you should see the reply box and
   a red number on "Messages".
4. Tap the "🎓 Learn" link at the top. Your Quizzes, Labs, Games and Class Record are there.


=====================================================================
PART 7 - MAKE YOURSELF THE ADMIN (2 minutes)
=====================================================================
1. First sign up on your site (Part 6) with your own email.
2. Supabase > SQL Editor > New query. Open database/3-make-me-admin.sql.
   Change  you@example.com  to the SAME email you used on the site. Run it.
3. On the site: log out, log in again. An "Admin" link appears at the top.
   There you can see reports, remove items, and ban users.


=====================================================================
IF SOMETHING GOES WRONG
=====================================================================
- Site says "Almost ready: connect the database":
    config.js is still empty, has a typo, or GitHub has not finished updating. Check the quotes,
    wait 2 minutes, refresh with Ctrl+Shift+R.
- "Invalid API key":  you copied the wrong key. Use the Publishable (or anon) key.
- SQL error mentions "already exists" or "column ... does not exist":
    you are on Option B and skipped file 1. Run 1-reset-old-marketplace.sql, then 2-setup.sql.
- Photos will not upload: Storage must show the "listing-photos" bucket (Public).
    If it is missing, run 2-setup.sql again.
- No sign-up email or "Email not confirmed":
    Authentication > Providers > Email > turn "Confirm email" OFF (testing), or set up SMTP.
- You do not see "Admin": the email in 3-make-me-admin.sql did not match, or you did not log
    out and in again.
- Reset password link opens the wrong page: fix Site URL and Redirect URLs in Part 4.

=====================================================================
[ ] Authentication > Email: "Confirm email" ON, and your own SMTP email sender set up.
[ ] config.js has your real contact email and operator name.
[ ] Read the Terms and Privacy pages on your site. They are a clear starting point,
    but I am not a lawyer. Ask your school or a legal adviser, especially if you will have

[ ] You are the moderator: check Admin > reports regularly and answer deletion requests.
[ ] Supabase Free plan has limits (storage, bandwidth) and can pause after about a week of no
    use. Check Supabase pricing. Consider a paid plan if the site grows.
[ ] No payments happen on the site. Users arrange payment and delivery themselves.
[ ] Chat checks for new messages every few seconds. There are no push notifications.
